# DataLens: вход по доменной учётке

Сервис даёт сотрудникам открывать DataLens логином и паролем Active Directory. Сам DataLens LDAP не умеет, поэтому перед ним стоит вход через Keycloak.

- DataLens — отчёты и воркбуки. Слушает только localhost, про AD ничего не знает. Своя форма логина выключена.
- Nginx — единственная точка входа с сети: HTTPS, два имени на один IP (datalens.internal — UI, auth.internal — вход), прокси на остальные модули.
- oauth2-proxy — проверяет, есть ли у браузера сессия. Нет — отправляет на Keycloak. Есть токен с ролью viewer — пускает на DataLens.
- Keycloak — форма входа, проверка пароля, выдача токена, выход. Realm datalens — контур этого приложения (не админка master).
- Postgres — база Keycloak. К данным отчётов не относится.
- Active Directory — логины и пароли. Keycloak спрашивает их по LDAP и сам пароли не хранит.

Все, кого пустили на сайт, видят один общий каталог воркбуков: внутри DataLens отдельных пользователей нет.
