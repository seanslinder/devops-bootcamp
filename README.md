# Sysadmin Bootcamp

Projects and exercises:

- [Backup Project](Backup%20Project/README.md): PowerShell script for automated folder backup with compression, logging, and error handling
- [Cisco VLAN](CiscoPT%20VLAN/README.md): Configuring a network topology (1 router + 1 switch + 2 PCs) with inter-VLAN routing
- Windows Server IIS:
  1) LVL 1: [IIS Setup](Windows%20Server%20IIS/LVL%201/README.md): Setting up a simple web application using IIS, including SSL certificate configuration and domain binding
- DataLens Project:
  1) [DataLens + Native Authorization](DataLens%20Project/DataLens+Native%20Auth/README.md): A test stand demonstrating PostgreSQL + Yandex DataLens Open Source on a virtual machine running RED OS
  2) [DataLens + KeyCloak](DataLens%20Project/DataLens+KeyCloak/README.md): DataLens and KeyCloak integration for logging in via Active Directory accounts
- [VMWare ESXi Practice](VMWare%20ESXi%20Practice/README.md): Create a Linux virtual machine in VMware ESXi, install a web server, make snapshots, and set resource limits
- [Rocky Linux](Rocky%20Linux/README.md): Manual deployment of MediaWiki on Rocky Linux 8 with a custom LVM layout and a Nginx, PostgreSQL and PHP stack
- [Observability](Observability/README.md): Deployment of Observability instruments: Zabbix server and Prometheus+Grafana stack, configuring Grafana Alerts
- [PostgreSQL Practice](PostgreSQL%20Practice/README.md): Installing PostgreSQL, creating a database and a custom table, making backups and restoring them, and configuring access control
- [ELK](ELK/README.md): Elasticsearch, Kibana and Logstash running in Docker, with Filebeat shipping logs and a Kibana dashboard for searching and visualizing errors
